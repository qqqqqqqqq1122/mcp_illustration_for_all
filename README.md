# MCP 工具全面说明书

> **Model Context Protocol (MCP)** 是由 Anthropic 推出的开放协议，用于让 AI 助手（如 Claude）安全、标准化地连接外部工具、数据源和服务。本文档对目前主流的 MCP 工具进行全面梳理，覆盖：是否需要远程服务器、能做什么、不能做什么、以及典型应用场景。

| 字段 | 说明 |
|------|------|

| **配置示例** | Claude Desktop 中的配置片段 |

## 一、文件与系统类

### 1. Filesystem（文件系统）

**运行方式**：🟢 **本地运行**（无需远程服务器）

**简介**：提供对本地文件系统的读写操作能力，是最基础的 MCP 工具之一。所有操作均在本地沙箱路径内进行，不涉及网络请求。

#### ✅ 能做什么

- 读取文件内容（支持文本、代码、配置等格式）
- 写入/创建新文件
- 修改/追加文件内容
- 列出目录中的文件和文件夹
- 移动、复制、重命名文件
- 删除文件或目录
- 搜索文件名或文件内容（含关键词匹配）
- 获取文件元信息（大小、修改时间、权限等）

#### ❌ 不能做什么

- **无法访问沙箱路径之外的目录**（必须在配置中显式声明允许的根路径）
- 不能执行文件（无法运行可执行程序）
- 不支持网络文件系统（NFS、SMB 等）的挂载操作
- 不能监听文件变化（无 watch 功能）
- 不能处理二进制文件的深度解析（如解压 zip、读取 PDF 内容等）

#### 📌 应用场景

1. **代码项目管理**：AI 帮助读取代码文件、修改 bug、添加注释、重构代码
2. **日志分析**：读取本地日志文件，分析错误模式
3. **配置文件管理**：读取并修改 `.env`、`config.yaml` 等配置文件
4. **批量文档处理**：遍历文件夹，批量整理/重命名文档
5. **笔记整理**：对本地 Markdown 笔记进行归类、搜索、编辑

#### ⚙️ 配置示例

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/yourname/projects"]
    }
  }
}
```

### 2. Memory（内存/知识图谱）

**运行方式**：🟢 **本地运行**（无需远程服务器）

**简介**：为 AI 提供持久化记忆能力，以知识图谱（Knowledge Graph）形式存储实体、关系和观察信息，数据保存在本地文件中，跨会话持久保留。

#### ✅ 能做什么

- 创建并存储"实体"（人物、地点、事物等概念节点）
- 定义实体之间的"关系"（如：张三 → 就职于 → ABC公司）
- 为实体添加"观察"（附加描述、备注等）
- 搜索知识图谱中的已有实体和关系
- 删除实体、关系或观察
- 跨会话保持记忆（不随对话结束而清除）

#### ❌ 不能做什么

- 不支持复杂的图查询语言（如 Cypher、SPARQL）
- 存储量受本地磁盘和性能限制，不适合海量数据
- 不提供自动推理或关联发现
- 不能与外部知识库（Wikipedia、企业 Wiki）自动同步
- 没有并发访问控制（多 Agent 同时写入可能冲突）

#### 📌 应用场景

1. **个人助手记忆**：记住用户的偏好、习惯、家庭成员信息，使对话更个性化
2. **项目知识库**：记录项目中的技术决策、人员分工、模块依赖关系
3. **客户关系管理**：记录客户信息、沟通历史、需求特征
4. **学习笔记**：构建学科知识点的关联图谱，辅助复习
5. **任务追踪**：记录未完成事项和上下文，避免反复说明背景

#### ⚙️ 配置示例

```json
{
  "mcpServers": {
    "memory": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-memory"]
    }
  }
}
```

### 3. Sequential Thinking（顺序思考）

**运行方式**：🟢 **本地运行**（无需远程服务器）

**简介**：让 AI 能够进行多步骤的结构化推理，将复杂问题分解为有序的思维步骤，每步可以基于前步结论再分析，支持回溯和修正。

#### ✅ 能做什么

- 将问题分解为若干连续思考步骤
- 在思考过程中标记某一步为"修正前步"
- 支持动态扩展思考步骤数（非线性推理）
- 给出最终分析结论
- 记录整个推理链，便于回溯审查

#### ❌ 不能做什么

- 本身不执行任何外部操作（不读文件、不调 API）
- 不保存思考结果到外部系统
- 思考内容仅在当前会话中有效，不持久化
- 不能替代专业领域知识（需结合其他工具）

#### 📌 应用场景

1. **复杂问题决策**：产品方案对比、架构设计权衡
2. **数学/逻辑推理**：多步骤计算、证明题分析
3. **代码调试**：逐步推断 bug 原因，缩小问题范围
4. **业务流程分析**：梳理业务流程中的瓶颈和优化点
5. **风险评估**：逐步分析项目/投资的潜在风险

### 4. Time（时间）

**运行方式**：🟢 **本地运行**（无需远程服务器）

**简介**：提供当前时间获取和时区转换能力，解决 AI 模型本身无法感知实时时间的问题。

#### ✅ 能做什么

- 获取当前本地时间（含时区信息）
- 在不同时区之间进行时间转换
- 计算两个时间点之间的时差

#### ❌ 不能做什么

- 不能设置系统时钟
- 不能创建定时任务或提醒
- 不提供日历功能（查询节假日等）
- 不能同步网络时间服务器（NTP）

#### 📌 应用场景

1. **跨时区协作**：将会议时间在北京、纽约、伦敦之间互相转换
2. **日志时间分析**：将 UTC 时间戳转为本地时间
3. **任务规划**：基于当前时间生成今日/本周计划
4. **时间感知对话**：AI 能回答"现在几点？""今天是星期几？"

## 二、数据库类

### 5. SQLite

**运行方式**：🟢 **本地运行**（无需远程服务器）

**简介**：连接本地 SQLite 数据库文件，支持完整的 SQL 查询与数据管理操作，无需任何数据库服务进程。

#### ✅ 能做什么

- 执行 SELECT 查询（含 JOIN、聚合、子查询等）
- 执行 INSERT / UPDATE / DELETE 数据操作
- 创建/修改/删除表结构（DDL 操作）
- 列出数据库中所有表和字段
- 读取表结构（schema）
- 执行事务操作

#### ❌ 不能做什么

- 不支持连接远程数据库（SQLite 本身是文件型数据库）
- 不支持并发写入（SQLite 的固有限制）
- 不能处理数据库文件损坏或加密的 SQLite 文件（需额外工具）
- 不支持存储过程或触发器的创建（仅执行 SQL）

#### 📌 应用场景

1. **本地数据分析**：对 SQLite 格式的应用数据（如 iOS 备份、浏览器历史）进行查询分析
2. **快速原型开发**：AI 辅助设计数据库 schema 并插入测试数据
3. **数据迁移**：读取旧 SQLite 数据，转换后写入新结构
4. **报表生成**：从本地数据库聚合数据，生成业务报表

#### ⚙️ 配置示例

```json
{
  "mcpServers": {
    "sqlite": {
      "command": "uvx",
      "args": ["mcp-server-sqlite", "--db-path", "/Users/yourname/data.db"]
    }
  }
}
```

### 6. PostgreSQL

**运行方式**：🟡 **需要数据库服务**（本地或远程均可，取决于连接字符串）

**简介**：连接 PostgreSQL 数据库，提供只读查询能力（官方版本默认只读，保护生产数据安全）。

#### ✅ 能做什么

- 执行只读 SQL 查询（SELECT）
- 列出所有数据库、schema、表、视图、索引
- 读取表结构和字段类型
- 查询系统表，了解数据库健康状态
- 生成查询的执行计划（EXPLAIN）

#### ❌ 不能做什么

- **默认不支持写操作**（INSERT/UPDATE/DELETE/DDL）
- 不执行存储过程（除非配置开放）
- 不进行数据库备份/恢复操作
- 不管理用户权限（GRANT/REVOKE）
- 不修改数据库配置参数

#### 📌 应用场景

1. **数据探索**：快速了解陌生数据库的结构和数据分布
2. **慢查询优化**：AI 分析 SQL 语句，提供索引建议
3. **业务报表**：用自然语言描述需求，AI 生成并执行 SQL
4. **数据库文档化**：自动生成数据库 ERD 描述文档

#### ⚙️ 配置示例

```json
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://localhost/mydb"]
    }
  }
}
```

### 7. MySQL

**运行方式**：🟡 **需要数据库服务**（本地或远程均可）

**简介**：连接 MySQL/MariaDB 数据库，提供 SQL 查询与数据操作能力（权限取决于连接账号配置）。

#### ✅ 能做什么

- 执行 SELECT 查询
- 执行写操作（INSERT/UPDATE/DELETE），权限由数据库账号控制
- 列出表和字段结构
- 执行 DDL（建表、改表等）
- 支持存储过程调用

#### ❌ 不能做什么

- 不能绕过数据库账号权限
- 不管理 MySQL 服务进程（启动/停止）
- 不进行备份/恢复（需结合 shell 工具）
- 不支持 MySQL Cluster 的特殊管理命令

#### 📌 应用场景

1. **Web 应用数据分析**：分析 WordPress、Magento 等常见 MySQL 应用的数据
2. **数据迁移辅助**：生成数据迁移脚本
3. **性能调优**：分析查询性能瓶颈，提供优化建议

### 8. MongoDB

**运行方式**：🟡 **需要数据库服务**（本地或远程均可）

**简介**：连接 MongoDB 数据库，支持文档查询、插入和集合管理，适合 NoSQL 文档型数据操作。

#### ✅ 能做什么

- 执行 find、aggregate 等查询操作
- 插入、更新、删除文档
- 列出数据库和集合
- 创建/删除索引
- 查看集合统计信息

#### ❌ 不能做什么

- 不管理 MongoDB 副本集或分片集群的配置
- 不执行 MapReduce 操作
- 不进行数据库用户管理
- 不支持全文搜索的高级配置

#### 📌 应用场景

1. **NoSQL 数据分析**：对非结构化数据进行聚合分析
2. **API 数据验证**：检查后端接口写入 MongoDB 的数据是否符合预期
3. **内容管理**：管理 CMS 系统的文档数据

### 9. Redis

**运行方式**：🟡 **需要 Redis 服务**（本地或远程均可）

**简介**：连接 Redis 缓存数据库，支持常见数据结构的读写操作，适合缓存管理和实时数据查看。

#### ✅ 能做什么

- GET/SET 字符串键值
- 操作列表（List）、集合（Set）、哈希（Hash）、有序集合（ZSet）
- 查看键的 TTL（过期时间）
- 查找匹配模式的键（KEYS/SCAN）
- 查看 Redis 服务器信息（INFO）

#### ❌ 不能做什么

- 不执行 Lua 脚本（EVAL）
- 不管理 Redis 集群拓扑
- 不进行 RDB/AOF 备份触发
- 不支持发布/订阅（Pub/Sub）的持续监听

#### 📌 应用场景

1. **缓存调试**：查看应用缓存内容，排查缓存穿透/雪崩问题
2. **Session 管理**：查看用户 Session 数据
3. **限流规则检查**：查看计数器和滑动窗口数据
4. **队列监控**：查看消息队列（List）中的待处理任务

## 三、Web 与网络类

### 10. Fetch（HTTP 请求）

**运行方式**：🟡 **需要网络连接**（但工具本身本地运行）

**简介**：让 AI 能够发起 HTTP/HTTPS 请求，获取网页内容或调用 Web API，是最基础的网络访问工具。

#### ✅ 能做什么

- 发起 GET 请求，获取网页 HTML 内容
- 将 HTML 自动转换为 Markdown 格式（便于 AI 处理）
- 发起 POST/PUT/DELETE 等 HTTP 方法
- 设置自定义请求头（Authorization、Content-Type 等）
- 发送 JSON 请求体
- 获取 REST API 响应数据

#### ❌ 不能做什么

- 不能执行 JavaScript（获取的是静态 HTML，动态内容不可见）
- 不能处理需要登录认证的页面（除非手动配置 Cookie/Token）
- 不能绕过反爬虫机制（如 Cloudflare 验证）
- 不支持 WebSocket 或 SSE 长连接
- 不能下载二进制文件（图片、PDF 等）

#### 📌 应用场景

1. **API 调试**：直接调用 REST API，查看响应结果
2. **网页内容提取**：获取公开网页的文章内容
3. **Webhook 测试**：发送测试请求到本地 Webhook 服务
4. **第三方服务集成**：调用天气、汇率、IP 查询等公共 API

#### ⚙️ 配置示例

```json
{
  "mcpServers": {
    "fetch": {
      "command": "uvx",
      "args": ["mcp-server-fetch"]
    }
  }
}
```

### 11. Brave Search（搜索引擎）

**运行方式**：🔴 **需要远程服务**（必须有 Brave Search API Key）

**简介**：使用 Brave 搜索引擎进行网络搜索，获取最新的网页搜索结果和本地商业信息，解决 AI 知识截止日期的问题。

#### ✅ 能做什么

- 执行网络搜索，返回相关网页列表（标题、URL、摘要）
- 搜索本地商业信息（餐厅、商店等，含地址、评分）
- 搜索新闻资讯
- 获取当前时事热点信息

#### ❌ 不能做什么

- 不能打开并读取搜索结果中的完整网页（仅返回摘要）
- 每日调用有频率限制（取决于 API 套餐）
- 不能搜索付费墙内容
- 搜索结果可能与 Google 有差异（索引覆盖度不同）
- 不支持高级搜索语法（如精确短语、排除词等全部功能）

#### 📌 应用场景

1. **实时信息获取**：搜索最新新闻、当前股价、今日赛事结果
2. **竞品调研**：搜索竞争对手的产品信息和用户评价
3. **技术文档查找**：搜索最新版本的 API 文档
4. **本地服务推荐**：搜索附近的餐厅、服务商

#### ⚙️ 配置示例

```json
{
  "mcpServers": {
    "brave-search": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-brave-search"],
      "env": {
        "BRAVE_API_KEY": "YOUR_API_KEY_HERE"
      }
    }
  }
}
```

### 12. Puppeteer（浏览器自动化）

**运行方式**：🟢 **本地运行**（需要本地安装 Chrome/Chromium）

**简介**：通过 Headless Chrome 实现浏览器自动化，能够访问动态网页、执行 JavaScript、截图和填写表单，是比 Fetch 更强大的网页交互工具。

#### ✅ 能做什么

- 导航到指定 URL，获取完整渲染后的页面内容
- 执行页面内的 JavaScript 代码
- 点击按钮、链接等页面元素
- 填写并提交表单
- 截取网页截图（全页或元素级别）
- 等待动态内容加载完成
- 处理弹窗和模态框

#### ❌ 不能做什么

## 常见问题 FAQ

**Q：MCP 工具的数据安全性如何？**  
A：本地运行的 MCP 工具（🟢）数据不离开本机，安全性最高。需要远程 API（🔴）的工具，数据会发送到对应的第三方服务，建议遵循最小权限原则，只授予 API Key 所需的最低权限。

**Q：多个 MCP 工具可以同时使用吗？**  
A：可以。在 Claude Desktop 的 `claude_desktop_config.json` 中，可以在 `mcpServers` 对象中同时配置多个工具，AI 会根据任务需要自动选择合适的工具。

**Q：MCP 工具会消耗 Claude 的 Token 吗？**  
A：工具的调用结果会作为上下文返回给 Claude，因此会占用 Context Window。返回大量数据的工具（如数据库查询、搜索结果）需要注意控制返回数量。

**Q：自己可以开发 MCP 工具吗？**  
A：可以。MCP 是开放协议，支持使用 TypeScript 或 Python SDK 开发自定义 MCP Server。详见 [MCP 官方文档](https://modelcontextprotocol.io)。
